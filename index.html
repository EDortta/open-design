Seu agente vira a camada de design do produto.

A ambição do repositório não para em UI: ele também cobre ativos visuais, prompts replicáveis e vídeo programático.

  • HyperFrames entra como camada nativa para motion graphics em MP4.

  • Boa vitrine para times que tratam design como sistema de produção multimídia.
Por que olhar este projeto

Infra para design com agentes, não só uma interface bonita.

A proposta central é transformar o laptop e o agente em um estúdio funcional, com skill protocol, daemon local, preview sandboxed e contratos visuais portáveis.

Filesystem-first

Artefato como arquivo canônico.

O produto trabalha com HTML, CSS, PDF, PPTX e MP4 como saída real, não só canvas fechado.

  • Iteração direta em arquivos.
  • Preview embutido em sandbox.
  • Handoff mais próximo de implementação.
Design system

`DESIGN.md` como contrato de marca portátil.

O README posiciona o design system como peça central para moldar toda saída do agente.

  • 151 pacotes visuais citados no roadmap atual.
  • Reuso entre protótipo, deck, dashboard e mídia.
  • Consistência sem depender de retrabalho manual.
Integração

Compatível com o stack de agentes já em uso.

Codex, Claude Code, Cursor, Copilot e vários CLIs entram pela mesma camada MCP e runtime local.

  • 25 executáveis locais distintos no README.
  • Suporte a BYOK via endpoint compatível com OpenAI.
  • Plugins para estender workflow sob demanda.
