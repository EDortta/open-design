Why look at this project

Infrastructure for design with agents, not only a pretty interface.

The core proposal is to turn the laptop and the agent into a working studio, with a skill protocol, local daemon, sandboxed preview, and portable visual contracts.

Filesystem-first

Artifact as the canonical file.

The product works with HTML, CSS, PDF, PPTX, and MP4 as real output, not only a closed canvas.

  • Direct iteration in files.
  • Embedded preview in sandbox.
  • Handoff closer to implementation.
Design system

The README positions the design system as a central piece for shaping every agent output.

  • 151 visual packages cited in the current roadmap.
  • Reuse across prototype, deck, dashboard, and media.
  • Consistency without depending on manual rework.
Integration

Compatible with the agent stack already in use.

Codex, Claude Code, Cursor, Copilot, and several CLIs come through the same MCP layer and local runtime.

  • 25 distinct local executables in the README.
  • BYOK support via an OpenAI-compatible endpoint.
  • Plugins to extend the workflow on demand.
